# 📝 List Manager

A dynamic, responsive task and list management web application built with HTML5, CSS3, and Vanilla JavaScript. It allows users to seamlessly add, edit, complete, and delete items with a live item counter and an animated gradient interface.

## 📌 Concise Repository Description (For GitHub "About" Section)

> A responsive dynamic list and task manager with CRUD functionality (Add, Edit, Complete, Delete), live item tracking, and an animated gradient UI built using HTML, CSS, and Vanilla JavaScript.

## ✨ Features

* **Full CRUD Functionality:**
  * **Create:** Add new items via the "Add" button or by pressing the `Enter` key, complete with empty-input validation.
  * **Update (Edit):** Modify existing list items on the fly using a recursive validation prompt.
  * **Complete:** Toggle task completion status with visual strike-through feedback.
  * **Delete:** Remove items with a safety confirmation dialog to prevent accidental deletions.
* **Live Item Counter:** Automatically increments and decrements the total item count as tasks are added or removed.
* **Animated Gradient UI:** Smooth keyframe background animation paired with custom gradient task cards.
* **Fully Responsive:** Adapts seamlessly across desktop, tablet, and mobile viewports (`1200px`, `900px`, `640px`, and `420px` breakpoints).

## 🛠️ Tech Stack

* **HTML5** – Semantic layout and structure
* **CSS3** – Linear gradients, `@keyframes` animations, Flexbox layout, and responsive media queries
* **Vanilla JavaScript** – DOM manipulation, event handling, and dynamic state updates

## 🚀 Getting Started

No external dependencies or build steps are required to run this project.

### 1. Clone the repository

```bash
git clone https://github.com/your-username/list-manager.git
```

### 2. Navigate to the project directory

```bash
cd list-manager
```

### 3. Open in Browser

Open `index.html` directly in your favorite browser, or launch it using the **Live Server** extension in VS Code.
